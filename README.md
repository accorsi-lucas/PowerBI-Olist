# 📊 **Dashboard Power BI - Olist**
Este repositório contém um **dashboard interativo no Power BI** baseado no **dataset da Olist**, uma plataforma de e-commerce brasileira.  

📌 **Objetivo:** Criar uma análise de vendas, avaliando o desempenho dos pedidos, faturamento, fretes e avaliações de clientes, com muita coisa ainda por vir.

📌 **Origem dos dados:** O projeto foi baseado no dataset disponível no **Kaggle**, disponível [neste notebook SQL](https://www.kaggle.com/code/terencicp/sql-challenge-e-commerce-data-analysis), que explora o dataset da Olist utilizando **consultas SQL**.

---

## 🚀 **Tecnologias Utilizadas**
- **Power BI** → Construção do dashboard e visualizações interativas.  
- **SQL / SQLite** → Extração dos dados da Olist.  
- **DAX (Data Analysis Expressions)** → Criação de cálculos personalizados.  

---

## 📂 **Dataset**
O conjunto de dados foi retirado do [Kaggle](https://www.kaggle.com/datasets/terencicp/e-commerce-dataset-by-olist-as-an-sqlite-database). Ele contém informações sobre pedidos, clientes, vendedores e produtos.

As principais tabelas utilizadas foram:
- **orders** (Pedidos)
- **order_items** (Itens dos pedidos)
- **customers** (Clientes)
- **order_reviews** (Avaliações)
- **order_payments** (Pagamentos)
- **sellers** (Vendedores)
- **geolocation** (Localização dos clientes)

---

## 📈 **Principais Análises e Gráficos**
- **Total de Vendas** (com e sem frete)  
- **Ticket Médio por Pedido**  
- **Vendas por Mês (Últimos 12 meses)**  
- **Distribuição das Formas de Pagamento**  
- **Média de Avaliações dos Clientes**  
- **Custo Médio do Frete**
